# Memory

## Présentation
Fantastique jeu du memory produit en HTML, CSS et JavaScript dans le cadre d'un mini-projet d'apprentissage du JavaScript pour ma deuxième année de BUT Informatique à l'Université de Caen Normandie.

## Technologies
Ce site web est codé principalement avec les technologies suivantes :
- **JavaScript (Vanilla)** : Cœur du projet, gestion de la logique du jeu, mélange des cartes et vérification des paires.
- **HTML5** : Structure de la page et de la grille de jeu.
- **CSS3** : Habillage visuel, animations de retournement des cartes et adaptation responsive.

## Fonctionnalités
- Génération aléatoire de la grille de cartes à chaque nouvelle partie.
- Animations fluides lors de la sélection et du retournement des cartes.
- Système de vérification des paires : maintien des cartes face visible si elles sont identiques, ou retournement masqué si elles sont différentes.
- Écran de victoire affiché lorsque toutes les paires ont été trouvées.
- Fonctionnalité pour recommencer une partie sans avoir à rafraîchir la page.
